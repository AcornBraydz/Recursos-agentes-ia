## 🧠 ¿Qué es un Agente de IA?

Un agente de IA es un sistema informático que puede percibir su entorno, tomar decisiones y actuar de forma autónoma (o semi-autónoma) para lograr un objetivo específico. A diferencia de un modelo de lenguaje puro (LLM) que solo responde a un prompt, un agente puede planificar, usar herramientas externas y corregir sus propios errores.
